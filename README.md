## 📌 Overview

This repository contains the implementation, benchmarking suite, and evaluation framework for a comparative study analyzing the efficiency of basic data structure operations on **Binary Search Trees (BST)** and **Treaps**.

The primary goal of this research is to evaluate and compare the time and space performance of both structures across various operations, input distributions, and dataset scales.

---

## 🔬 Scope of Study

The efficiency of both structures is evaluated based on standard operations across varying workloads and scaling factors:

* **Operations Evaluated:**
  * Insertion (`Insert`)
  * Deletion (`Delete`)
  * Search / Lookup (`Search`)
* **Workload & Data Configurations:**
  * Sequential / Sorted inputs (worst-case scenarios for unbalanced BSTs)
  * Randomly distributed inputs
  * Mixed read/write operation ratios
* **Dataset Sizes:** Small-scale testing up to large $N$ performance tests.
